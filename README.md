# Wilson Neto — academic website

This folder contains the static files for the new version of `willneto.github.io`.

## Pages

- `index.html` — homepage
- `research.html` — working papers and job market paper
- `contact.html` — contact information
- `contato.html` and `porrtfolio.html` — redirects that preserve the old public URLs

## Publishing on GitHub Pages

Copy the contents of this folder to the root of the `willneto.github.io` repository. Keep the `assets` folder structure unchanged so the stylesheet and portrait paths continue to work.

Before publishing, check that the canonical domain in the HTML files, `robots.txt`, and `sitemap.xml` is still `https://willneto.github.io`.
